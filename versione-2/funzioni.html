Cosa fa FileGuard

Le funzioni una per una, con le schermate del programma.

Monitoraggio continuo

Cartelle e file restano sotto osservazione, e ogni operazione finisce nel diario, con il computer da cui è partita. Nelle cartelle protette, se un file viene modificato o sparisce dalla cartella, perché cancellato o spostato altrove, arriva l'avviso.

Il preventivo di un paziente sparisce da una cartella protetta: arriva l'avviso.

Le regole

Su ogni cartella scegli le regole che ti servono. FileGuard ti avvisa; cosa fare lo decidi tu.

Regola Cosa vedi Esempio di cartella
Non si cancella Arriva l'avviso se un file viene eliminato Cartelle cliniche
Non si modifica Resta la traccia e arriva l'avviso se un file viene modificato Contratti firmati
Non esce di qui presto Vedi dove è finito un file uscito dalla cartella Referti
Deve esserci Vedi se manca un file che deve stare nella cartella Fascicolo antiriciclaggio
Non si tiene per sempre presto Vedi da quanto tempo i file sono nella cartella Documenti di ex clienti

Avviso e ripristino

Dall'avviso vedi cosa manca. Se è stato un errore, apri la finestra delle versioni e rimetti il file con «Ripristina».

"contratto.pdf eliminato dal PC ufficio": apri le versioni del contratto e lo ripristini.

Copie e versioni

Le copie restano sui tuoi computer, o nelle cartelle che scegli tu: disco, server, NAS, anche in doppia copia. Le copie possono andare anche in una cartella sincronizzata con il tuo servizio cloud. Le modifiche lasciano una versione, secondo la conservazione che scegli.

Hai salvato sopra il contratto? Apri le versioni e ritrovi quella di ieri.

Privacy e GDPR sui file

Trova, nelle cartelle sorvegliate, i documenti di una persona e ripercorre la storia di ogni file.

Un cliente chiede quali dati conservi su di lui.

Marca temporale presto

Fissa la data e l'ora in cui un documento era così com'è, per mostrarlo se qualcuno te lo chiede.

Installazione

Lo installi con una procedura guidata.

Requisiti: Windows 10 (dalla versione 1809, ottobre 2018) e Windows 11.
